- **Что такое командная строка?**  
    Командная строка — это текстовый интерфейс для взаимодействия с операционной системой, в котором пользователь вводит команды для выполнения различных операций, таких как навигация по файловой системе, запуск программ и управление процессами.
- **При помощи какой команды можно определить абсолютный путь текущего каталога? Приведите пример.**  
    Команда:

bash

CopyEdit

pwd  

Пример вывода:

bash

CopyEdit

/home/user  

- **При помощи какой команды и каких опций можно определить только тип файлов и их имена в текущем каталоге? Приведите примеры.**  
    Команда:

bash

CopyEdit

ls -F  

Пример вывода:

bash

CopyEdit

Documents/ script.sh\* link@  

Здесь / обозначает каталог, \* — исполняемый файл, @ — символическая ссылка.

- **Каким образом отобразить информацию о скрытых файлах? Приведите примеры.**  
    Используйте команду:

bash

CopyEdit

ls -a  

Пример вывода:

bash

CopyEdit

.bashrc .profile Documents Downloads  

- **При помощи каких команд можно удалить файл и каталог? Можно ли это сделать одной и той же командой? Приведите примеры.**
- Удаление файла:

bash

CopyEdit

rm filename.txt  

- Удаление пустого каталога:

bash

CopyEdit

rmdir foldername  

- Удаление каталога с файлами:

bash

CopyEdit

rm -r foldername  

Да, командой rm -r можно удалять как файлы, так и каталоги.

- **Каким образом можно вывести информацию о последних выполненных пользователем командах?**  
    Используется команда:

bash

CopyEdit

history  

- **Как воспользоваться историей команд для их модифицированного выполнения? Приведите примеры.**
- Повторить последнюю команду:

bash

CopyEdit

!!  

- Выполнить команду с определённым номером из history:

bash

CopyEdit

!15  

- Заменить часть команды из истории:

bash

CopyEdit

!3:s/old/new  

- **Приведите примеры запуска нескольких команд в одной строке.**
- Последовательное выполнение команд:

bash

CopyEdit

cd /tmp; ls  

- Выполнение только при успешном завершении первой команды:

bash

CopyEdit

mkdir newdir && cd newdir  

- Выполнение следующей команды, даже если первая завершится ошибкой:

bash

CopyEdit

mkdir test || echo "Ошибка создания каталога"  

- **Дайте определение и приведите примеры символов экранирования.**  
    Символы экранирования используются для отключения специального значения символов.
- \\ — экранирование одиночного символа:

bash

CopyEdit

echo "Hello\\$USER"  

- Кавычки:

bash

CopyEdit

echo "Это 'текст' в кавычках"  

- **Охарактеризуйте вывод информации на экран после выполнения команды ls с опцией l.**
- ls -l выводит детальную информацию о файлах и каталогах:

bash

CopyEdit

\-rw-r--r-- 1 user user 1024 Mar 22 12:00 file.txt  

Это включает:

- - Права доступа (-rw-r--r--)
    - Количество ссылок (1)
    - Владелец (user)
    - Группа (user)
    - Размер файла (1024 байта)
    - Дата последнего изменения (Mar 22 12:00)
    - Имя файла (file.txt)
- **Что такое относительный путь к файлу? Приведите примеры использования относительного и абсолютного пути при выполнении какой-либо команды.**
- Абсолютный путь:

bash

CopyEdit

cd /home/user/documents  

- Относительный путь:

bash

CopyEdit

cd documents  

В первом случае путь начинается от корня /, а во втором — относительно текущего каталога.

- **Как получить информацию об интересующей вас команде?**  
    Используйте команду man:

bash

CopyEdit

man ls  

Или краткую справку:

bash

CopyEdit

ls --help  

- **Какая клавиша или комбинация клавиш служит для автоматического дополнения вводимых команд?**  
    **Tab** (дважды) — автоматически дополняет команды или файлы.
